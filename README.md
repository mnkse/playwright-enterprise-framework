# Playwright Enterprise Test Automation Framework

This repository contains an enterprise-level test automation framework built with Playwright and TypeScript.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- GitHub Actions
- Page Object Model
- UI and API test structure

## Project Structure

```text
playwright-enterprise-framework
├── .github/workflows
├── configs
├── fixtures
├── pages
├── test-data
├── tests
│   ├── ui
│   └── api
├── utils
├── playwright.config.ts
└── package.json
```
